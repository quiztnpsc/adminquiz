Revision Quiz app

1. Quick use: open index.html in a browser (works offline, data stays on that device).
2. Install as a phone/desktop app: upload all these files to any web host (Netlify Drop, GitHub Pages, etc.), open the https link on your phone, then choose 'Add to Home screen' / 'Install app'.

Note: this copy keeps students and scores on each device only. For one shared class list across devices, use the web link.
